# 음식 사진 폴더

요리 탭 메뉴의 예시 사진을 넣는 곳이에요.

1. 사진을 이 폴더에 넣어요. 예: `lohikeitto.jpg`
2. `data/meals.js`에서 그 메뉴에 `image: 'lohikeitto.jpg'`를 적어요. 파일 이름만 적으면 돼요.

- 사진이 없거나 이름이 틀리면 종류 아이콘(🍲 등)이 대신 보여요.
- 가로로 긴 사진이 잘 어울려요. 카드 위쪽에 띠 모양으로 잘려서 보여요.
- 용량은 장당 300KB 안팎을 권장해요. 폰에서 빨리 뜨고, 오프라인 저장 공간도 아낄 수 있어요.
- 한 번 본 사진은 자동으로 저장돼서 오프라인에서도 보여요.
